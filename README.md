# Money Signal — 資産形成のためのニュースアプリ

資産を増やすための判断材料になるニュース（**経済・マーケット / 世界情勢 / テクノロジー / 暗号資産**）と、選んだジャンル（例: **ゲーム業界**）のニュースを集めて表示するニュースリーダーです。
スマホでも PC でも同じ URL で閲覧でき、ホーム画面に追加すればアプリのように使えます（PWA）。

## 主な機能

- **AI まとめ**: 毎日朝7時・夕方6時に、Claude が設定したプロンプトに従って重要ニュースを5〜8件選び、概況・要約・解説を作成。まとめは複数作れ（初期設定は「重要ニュース（資産形成）」と「ゲーム業界」）、過去30日分を日付ごとに閲覧可能
- **ジャンル選択**: 経済・マーケット / 世界情勢 / テクノロジー / 暗号資産 / ゲーム業界 から収集するジャンルを `settings.yml` で選択。表示するジャンルはアプリの設定から端末ごとに切り替え可能
- **ノイズ除去**: スポーツ・芸能・セール情報など資産形成に関係の薄い記事を自動で除外
- **トピックタグ**: 金利・中銀 / 為替 / 株式 / 決算・企業 / 景気・物価 / 政策・税制 / 地政学 / エネルギー・資源 / AI / 半導体 / 不動産 / 暗号資産 を自動付与し、タップで絞り込み
- **マーケット指標**: 日経平均、S&P 500、NASDAQ、NYダウ、ドル円、米10年債利回り、金、WTI原油、ビットコイン の前日比
- **キーワード検索**、**日本語/英語の切り替え**、英語記事の**ワンタップ翻訳**（Google 翻訳で開く）
- **後で読む（保存）**、**既読管理**、**ミュートキーワード**、**ソースの表示/非表示**
- **レスポンシブ**: スマホは1カラム + 横スクロールタブ、PC はサイドバー + 2〜3カラム
- **ダークモード**対応、**オフライン**でも直近のニュースを閲覧可能

設定・保存記事・既読はブラウザ（端末）ごとに保存されます。

## 仕組み

サーバーを持たない構成で、無料で運用できます。

```
GitHub Actions（約30分ごと）
  └─ scripts/fetch-news.mjs が RSS とマーケット指標を取得・分類・フィルタ
       └─ public/data/news.json, markets.json を生成
            └─ public/ を GitHub Pages にデプロイ → スマホ / PC のブラウザで閲覧
```

ブラウザから直接 RSS を取得すると CORS 制限で失敗するため、収集はサーバー側（Actions）で行い、静的な JSON として配信しています。

## 公開手順（GitHub Pages）

1. このブランチを `main` にマージします（定期実行のスケジュールはデフォルトブランチでのみ動きます）。リポジトリの **Settings → General → Default branch** が `main` になっていることも確認してください。
2. **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
3. **Actions** タブで「Update news & deploy」を選び **Run workflow** で初回実行します。
4. 完了すると `https://<ユーザー名>.github.io/NewsApp/` で閲覧できます。以降は約30分ごとに自動更新されます。

> プライベートリポジトリで GitHub Pages を使うには有料プランが必要です。無料プランの場合はリポジトリを公開してください（収集するのは公開ニュースのみで、個人データは含みません）。

### AI まとめ（要約）を有効にする

要約には Claude Code を使います。Claude の有料プラン（Pro / Max）の利用枠で動くため、API の従量課金はかかりません（1日2回の実行分だけプランの利用量を消費します）。

1. PC に [Node.js](https://nodejs.org/) をインストールし、ターミナル（Windows は PowerShell）で次を実行します。
   ```bash
   npm install -g @anthropic-ai/claude-code
   claude setup-token
   ```
   ブラウザで Claude にログインすると、`sk-ant-oat01-…` で始まるトークンが表示されます。**このトークンは他人に見せないでください。**
2. GitHub のリポジトリで **Settings → Secrets and variables → Actions → New repository secret** を開き、
   Name に `CLAUDE_CODE_OAUTH_TOKEN`、Secret に手順1のトークンを貼り付けて保存します。
3. **Actions → Update news & deploy → Run workflow**（「AI まとめも生成する」にチェック）で初回のまとめを作成します。

以降は毎日 日本時間 7:03 と 18:03 に自動で更新されます（同じ日のまとめは夕方の実行で最新の内容に置き換わります）。
トークンを設定していない場合や生成に失敗した場合でも、ニュース一覧は通常どおり更新されます。
まとめの履歴は公開中のサイトから引き継ぐため、リポジトリにコミットは増えません。

### スマホのホーム画面に追加する

- **iPhone (Safari)**: 共有ボタン →「ホーム画面に追加」
- **Android (Chrome)**: メニュー →「ホーム画面に追加」/「アプリをインストール」

## 設定（settings.yml）

収集するジャンルと AI まとめのプロンプトは、リポジトリ直下の [`settings.yml`](settings.yml) で設定します。
アプリの「設定 → 収集するジャンルと AI まとめ →『設定を編集する（GitHub）』」から、GitHub の編集画面を直接開けます。
編集して **Commit changes** で保存すると、数分後にニュースの収集と AI まとめが新しい設定でやり直されます。

```yaml
genres:            # 収集するジャンル（markets / world / tech / crypto / games）
  - markets
  - games

digests:           # AI まとめ（いくつでも追加可能）
  - id: games      # 英数字の識別名（変えると過去のまとめは引き継がれません）
    name: ゲーム業界
    genres: [games]
    label: 業界への影響   # 各ニュースの解説の見出し
    prompt: |
      ゲーム業界の動向を追いたい読者に向けて、今日の重要なニュースを選んでください。
      …（何を重要とみなすか、どんな観点で書くかを自由に記述）
```

- `prompt` には「何を重要とみなすか」「どの観点で解説するか」を書きます。出力の形式や根拠記事の扱いは自動で付け足されます。
- 設定に誤りがあると、Actions のログに日本語で原因が表示され、サイトは直前の状態のまま保たれます。
- まとめを増やすと、その分だけ Claude の利用量が増えます（1つのまとめにつき1日2回）。

## ローカルで動かす

Node.js 20 以上が必要です。

```bash
npm install
npm run dev      # ニュースを取得してから http://localhost:8080 で起動
npm test         # テスト
```

同じ Wi-Fi 内のスマホからは `http://<PCのIPアドレス>:8080` で確認できます。

## カスタマイズ

選べるジャンル・取得元・除外キーワード・トピック・マーケット指標は [`config/feeds.mjs`](config/feeds.mjs) で定義しています。

- **ニュースソースを追加**: `FEEDS` に `{ name, url, category, lang }` を追加（RSS 2.0 / RSS 1.0 / Atom に対応。`category` はジャンルの id）
- **ジャンルを追加**: `GENRES` に追加し、そのジャンルの `FEEDS` を登録すると `settings.yml` で選べるようになります
- **除外したい話題**: `EXCLUDE_KEYWORDS`（ゲーム業界は `GAMES_EXCLUDE_KEYWORDS`）に追加
- **タグを追加**: `TOPICS` にキーワードとともに追加
- **指標を追加**: `MARKETS` に Yahoo Finance のシンボル（例: `^TPX`、`EURJPY=X`）を追加

取得に失敗したソースはアプリの「設定 → ニュースソース」に「取得失敗」と表示されます。他のソースは影響を受けません。

## ディレクトリ構成

```
settings.yml              収集するジャンルと AI まとめの設定（利用者が編集）
config/feeds.mjs          選べるジャンル・取得元・フィルタの定義
scripts/fetch-news.mjs    ニュース・指標の取得（Actions から実行）
scripts/lib.mjs           フィード解析・正規化・フィルタ（テスト対象）
scripts/settings.mjs      settings.yml の読み込みと検証（テスト対象）
scripts/digest.mjs        AI まとめの生成・30日分の引き継ぎ
scripts/digest-lib.mjs    まとめ用のプロンプト・検証（テスト対象）
scripts/serve.mjs         ローカル確認用サーバー
public/                   フロントエンド（HTML/CSS/JS, PWA）
test/                     テスト
.github/workflows/        自動収集・デプロイ、テスト
```

## 注意

- 記事の見出しと要約は各配信元の RSS に基づきます。全文は配信元サイトで閲覧してください。
- マーケット指標は約30分ごとの取得時点の値で、リアルタイムではありません。
- 重要ニュースのまとめは AI が見出しをもとに作成したもので、誤りを含む可能性があります。投資判断はご自身の責任で行ってください。
