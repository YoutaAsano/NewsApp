# Money Signal — 資産形成のためのニュースアプリ

資産を増やすための判断材料になるニュース（**経済・マーケット / 世界情勢 / テクノロジー / 暗号資産**）だけを集めて表示するニュースリーダーです。
スマホでも PC でも同じ URL で閲覧でき、ホーム画面に追加すればアプリのように使えます（PWA）。

## 主な機能

- **カテゴリ別表示**: 経済・マーケット、世界情勢、テクノロジー、暗号資産、保存済み
- **ノイズ除去**: スポーツ・芸能・セール情報など資産形成に関係の薄い記事を自動で除外
- **トピックタグ**: 金利・中銀 / 為替 / 株式 / 決算・企業 / 景気・物価 / 政策・税制 / 地政学 / エネルギー・資源 / AI / 半導体 / 不動産 / 暗号資産 を自動付与し、タップで絞り込み
- **マーケット指標**: 日経平均、S&P 500、NASDAQ、NYダウ、ドル円、米10年債利回り、金、WTI原油、ビットコイン の前日比
- **キーワード検索**、**日本語/英語の切り替え**、英語記事の**ワンタップ翻訳**（Google 翻訳で開く）
- **後で読む（保存）**、**既読管理**、**ミュートキーワード**、**ソースの表示/非表示**
- **レスポンシブ**: スマホは1カラム + 横スクロールタブ、PC はサイドバー + 2〜3カラム
- **ダークモード**対応、**オフライン**でも直近のニュースを閲覧可能

設定・保存記事・既読はブラウザ（端末）ごとに保存されます。

## 仕組み

サーバーを持たない構成で、無料で運用できます。

```
GitHub Actions（約30分ごと）
  └─ scripts/fetch-news.mjs が RSS とマーケット指標を取得・分類・フィルタ
       └─ public/data/news.json, markets.json を生成
            └─ public/ を GitHub Pages にデプロイ → スマホ / PC のブラウザで閲覧
```

ブラウザから直接 RSS を取得すると CORS 制限で失敗するため、収集はサーバー側（Actions）で行い、静的な JSON として配信しています。

## 公開手順（GitHub Pages）

1. このブランチを `main` にマージします（定期実行のスケジュールはデフォルトブランチでのみ動きます）。リポジトリの **Settings → General → Default branch** が `main` になっていることも確認してください。
2. **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
3. **Actions** タブで「Update news & deploy」を選び **Run workflow** で初回実行します。
4. 完了すると `https://<ユーザー名>.github.io/NewsApp/` で閲覧できます。以降は約30分ごとに自動更新されます。

> プライベートリポジトリで GitHub Pages を使うには有料プランが必要です。無料プランの場合はリポジトリを公開してください（収集するのは公開ニュースのみで、個人データは含みません）。

### スマホのホーム画面に追加する

- **iPhone (Safari)**: 共有ボタン →「ホーム画面に追加」
- **Android (Chrome)**: メニュー →「ホーム画面に追加」/「アプリをインストール」

## ローカルで動かす

Node.js 20 以上が必要です。

```bash
npm install
npm run dev      # ニュースを取得してから http://localhost:8080 で起動
npm test         # テスト
```

同じ Wi-Fi 内のスマホからは `http://<PCのIPアドレス>:8080` で確認できます。

## カスタマイズ

取得元・除外キーワード・トピック・マーケット指標はすべて [`config/feeds.mjs`](config/feeds.mjs) で設定します。

- **ニュースソースを追加**: `FEEDS` に `{ name, url, category, lang }` を追加（RSS 2.0 / RSS 1.0 / Atom に対応）
- **除外したい話題**: `EXCLUDE_KEYWORDS` に追加
- **タグを追加**: `TOPICS` にキーワードとともに追加
- **指標を追加**: `MARKETS` に Yahoo Finance のシンボル（例: `^TPX`、`EURJPY=X`）を追加

取得に失敗したソースはアプリの「設定 → ニュースソース」に「取得失敗」と表示されます。他のソースは影響を受けません。

## ディレクトリ構成

```
config/feeds.mjs          取得元・分類・フィルタ設定
scripts/fetch-news.mjs    ニュース・指標の取得（Actions から実行）
scripts/lib.mjs           フィード解析・正規化・フィルタ（テスト対象）
scripts/serve.mjs         ローカル確認用サーバー
public/                   フロントエンド（HTML/CSS/JS, PWA）
test/                     テスト
.github/workflows/        自動収集・デプロイ、テスト
```

## 注意

- 記事の見出しと要約は各配信元の RSS に基づきます。全文は配信元サイトで閲覧してください。
- マーケット指標は約30分ごとの取得時点の値で、リアルタイムではありません。投資判断はご自身の責任で行ってください。
